# Cursor

Copy [mcp.json](mcp.json) to `.cursor/mcp.json` in a project, or to `~/.cursor/mcp.json` for all projects. Fix the path to your cyai clone, then enable **cyai** under *Settings → MCP*.

In Agent chat, ask: "Run a cyai mock interview with me." The agent will call `list_interviews` and take it from there.
