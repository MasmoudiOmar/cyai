# Codex CLI

Add the server to `~/.codex/config.toml` (see [config.toml](config.toml)):

```bash
codex mcp add cyai -- node /absolute/path/to/cyai/packages/cli/dist/bin.js mcp
```

Optionally append [AGENTS.md](AGENTS.md) to the `AGENTS.md` of the folder where you practise, so Codex knows how to run the session. Then ask: "Give me a mock AI interview."
